# iConic Tecnologia — site

Site estático publicado pelo GitHub Pages em https://www.iconictecnologia.com.br.

O código-fonte (modelos, textos, imagens originais e scripts) fica fora deste repositório; aqui vai só o site pronto (`dist/` do projeto) e o arquivo `CNAME` com o domínio.

Créditos da sala interativa da página inicial: imagens ilustrativas geradas por IA; músicas de Kevin MacLeod (incompetech.com), licença CC BY 4.0, em trechos editados; imagens da Terra na TV: NASA.
